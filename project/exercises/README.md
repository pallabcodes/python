# Exercises

Progressive hands-on exercises for mastering Python concurrency and parallelism.

## Organization

Exercises are organized by difficulty level:

- **beginner/** - Basic concepts and simple implementations
- **intermediate/** - Synchronization, pools, and common patterns
- **advanced/** - Complex scenarios, performance optimization, distributed systems

## Learning Path

### Beginner Exercises
Start here if you're new to concurrency:
- Basic thread creation
- Simple async functions
- Basic process creation
- Simple executor usage

### Intermediate Exercises
Build on fundamentals:
- Thread synchronization
- Process pools
- Async patterns
- Common concurrency patterns
- Error handling

### Advanced Exercises
Master complex scenarios:
- Complex synchronization
- Distributed scenarios
- Performance optimization
- Debugging concurrent code
- Real-world system design

## How to Use

1. Read the exercise description
2. Review related examples in `../examples/`
3. Implement your solution
4. Test your implementation
5. Compare with provided solutions (if available)
6. Refactor and optimize

## Exercise Structure

Each exercise should include:
- Problem description
- Requirements
- Hints (optional)
- Expected behavior
- Testing guidelines

## Tips

- Start with beginner exercises even if experienced
- Read the core concepts first (`../core/`)
- Study examples before implementing
- Test thoroughly with concurrent scenarios
- Profile your solutions for performance
