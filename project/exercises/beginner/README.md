# Beginner Exercises

Basic exercises for getting started with Python concurrency and parallelism.

## Topics Covered

- Basic thread creation and management
- Simple async functions
- Basic process creation
- Simple executor usage
- Basic synchronization

## Prerequisites

- Understanding of Python basics
- Familiarity with functions and classes
- Basic knowledge of file I/O

## Learning Goals

After completing beginner exercises, you should be able to:
- Create and manage threads
- Write basic async functions
- Create and manage processes
- Use basic executors
- Understand basic synchronization needs

## Exercises

1. **Basic Threading** - Create and run simple threads
2. **Basic Asyncio** - Write simple async functions
3. **Basic Multiprocessing** - Create and run simple processes
4. **Basic Executors** - Use ThreadPoolExecutor and ProcessPoolExecutor
5. **Simple Synchronization** - Basic lock usage

## Getting Started

1. Review core concepts in `../../core/`
2. Study examples in `../../examples/`
3. Start with exercise 1
4. Work through exercises sequentially
